TABESA RESTAURANT & CAFE WEBSITE
Tagline: Good Food. Great Moments.

Open index.html in a modern browser after extracting the ZIP.

Features:
- Home, Menu, About, Contact, Cart, Checkout and Success pages
- JavaScript menu search and category filtering
- Shopping cart with quantity controls
- Automatic subtotal, delivery fee and total
- Customer checkout form
- Cash on Delivery, GCash and Card demo options
- Order confirmation
- Responsive mobile design
- localStorage cart persistence

This is a front-end/demo website. It does not process real payments or send real orders to a restaurant server.
